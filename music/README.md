# Music Directory

This directory contains musical compositions and soundscapes for TimeWalk projects.

## Structure

- **compositions/** - Original musical compositions for different historical periods
- **soundscapes/** - Ambient audio environments for historical settings  
- **sound-effects/** - Individual sound effects and audio clips

## Organization

Files should be organized by:
- Historical period (e.g., `1600s/`, `1700s/`, `1800s/`)
- Location (e.g., `manhattan/`, `mill-valley/`)
- Type of audio content

## File Formats

- Source files: High-quality formats (.wav, .aiff, .flac)
- Distribution files: Compressed formats (.mp3, .ogg) as needed
- Project files: DAW-specific project files when applicable

## Contributing

When adding music:
1. Include source documentation about historical accuracy
2. Provide metadata about time period, location, and instruments used
3. Include both high-quality source and compressed distribution versions
